# 瞳击 EYE ROYALE

不开枪的吃鸡。每个人胸口和额头都写着 4 位数字，看清对手的数字并抢先用键盘敲出来，就是一次攻击。

纯前端网页游戏（Three.js），无需服务器、无需构建，所有文件都在 `public/` 里。

## 核心规则

- **读码攻击**：看清敌人身上的数字，按键盘数字键输入（主键盘或小键盘），满 4 位自动出手。
- **头部 100%，身体 50%**：额头的数字更小更难看清，但伤害翻倍。
- **防具百分比减伤**：一/二/三级头盔与护甲分别减伤 30% / 40% / 55%，有耐久，打坏会掉。
- **受伤即换码**：每次被读中，自己的两串数字都会重新随机（毒圈伤害不会重置）。
- **数字只在正面**：背对你的人读不到。带扫描器靠近背对你的敌人，4 秒后显示他的数字（8 秒内有效）。
- **缩圈大地图**：1.2 km 岛屿，9 个左右城镇，7 个缩圈阶段，两次空投。
- **跳伞**：运输机航线随机，F 跳伞、F 开伞（100 米自动开伞），W 俯冲。

## 读码武器

搜到读码卡后按 **R** 切换，规则不同、伤害不同：

| 武器 | 怎么输入 | 伤害 |
| --- | --- | --- |
| 标准读码 | 照着输入 4 位 | ×1.0 |
| 速读码 | 只输入前 3 位 | ×0.6 |
| 反读码 | 倒着输入 4 位 | ×1.4 |
| 破甲码 | 每位 +1 输入（9 变 0） | ×1.0，无视头盔护甲 |
| 狙读码 | 开 4 倍以上镜时照着输入 | ×1.6 |

## 训练场

菜单里点“训练场”。岛上有一条固定靶场（大地图上标着“训练靶场”，吃鸡模式里也在），木人站在 10 / 18 / 24 / 32 / 45 / 60 / 100 / 150 米：
18 米躲在矮墙后只能读头，24 米背对你练扫描器，32 米左右移动，45 米带干扰涂层，60 米穿三级头甲（试试破甲码）。
左上角统计命中、读错、准确率和读码用时（数字出现在视野里到你读中为止）。

## 特色玩法

- **读错锁定**：输错会锁定输入 0.5 → 0.8 → 1.2 → 1.6 秒（连续读错递增），乱按没用。
- **被注视警告**：有人正在读你的数字时，屏幕上出现指向他的“眼睛”，越红越危险。
- **干扰涂层**：15 秒内你的数字布满杂讯和假数字，更难被看清。
- **掩体只露头**：城镇里的矮墙刚好挡住胸口，只能去读更小的头部数字。
- **草丛藏身**：草丛会挡住视线，蹲在草里能藏住数字。
- **脚步声**：附近敌人奔跑会有左右声道的脚步声——听到背后有人，回头就会暴露自己的数字。
- **扫描警告**：有人在你背后扫描时会提示，转身或离开即可打断。

## 部署到 Cloudflare

仓库根目录有 `wrangler.jsonc`，静态资源目录是 `public/`：

- **Workers（推荐，和之前项目一样）**：Cloudflare 控制台 → Workers & Pages → 创建 → 导入 Git 仓库 `kaleomi/eye-royale`，构建命令留空，部署命令用默认的 `npx wrangler deploy` 即可。
- **Pages**：导入仓库，构建命令留空，输出目录填 `public`。

视角跳变：Chrome 在锁定鼠标时偶尔会报一次巨大的鼠标位移，导致视角瞬间转半圈。游戏里优先请求原始鼠标输入，并丢弃锁定后 150ms 内和明显异常的位移。

本地试玩：在 `public/` 目录下运行任意静态服务器（例如 `python3 -m http.server`），浏览器打开即可。直接双击 html 打不开（ES 模块需要 http）。

## 代码结构

```
public/
  index.html      界面与样式
  lib/            three.js r169（已内置，不依赖 CDN）
  src/
    main.js       主循环、对局流程、事件
    world.js      岛屿地形、城镇建筑、植被、碰撞与视线检测
    character.js  角色模型与数字牌
    actor.js      玩家/机器人共用属性、受伤、物品使用
    combat.js     读码判定、扫描器、闪光
    player.js     玩家输入、移动、镜头
    bot.js        机器人 AI（跳伞、搜刮、进圈、读码对战、闪光/烟雾/涂层）
    items.js      物资、拾取、投掷物、烟雾、空投
    zone.js       缩圈
    plane.js      运输机
    hud.js        HUD、小地图、大地图
    training.js   训练场木人与读码用时统计
    audio.js      合成音效
    config.js     数值配置（伤害、减伤、圈、掉落表都在这里调）
```

目前是单机版：玩家 + 19/29/39 个 AI 对手。之后要做真人联机，可以在 Cloudflare 上加一个 Durable Objects 房间服务器同步位置和读码事件。
